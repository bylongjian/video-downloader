# 🚀 保姆级本地运行指南

这份指南按七步启动 SaveAny 前后端。先跑通视频解析和下载，再按需配置 AI、语音转写和测试支付。

以下命令以 **Windows PowerShell** 为例，除明确进入 `frontend` 外，都从项目根目录 `video-downloader` 执行。已有代码、虚拟环境和配置可以继续使用。

## 前置要求

先确认 Python、Node.js 和媒体工具可用，再安装项目依赖。

| 工具 | 要求 | 检查命令 | 获取方式 |
|------|------|----------|----------|
| Python | 3.11 或更新的兼容版本 | `python --version` | [Python 官网](https://www.python.org/downloads/) |
| Node.js / npm | Node.js 22.12+ | `node -v`、`npm.cmd -v` | [Node.js 官网](https://nodejs.org/en) |
| ffmpeg / ffprobe | 加入 PATH | `ffmpeg -version`、`ffprobe -version` | [ffmpeg 官网](https://ffmpeg.org/download.html) |
| Git | 能使用命令行 | `git --version` | [Git 官网](https://git-scm.com/) |

ffmpeg 用于音视频合并，ffprobe 用于检查音轨时长。缺少 ffmpeg 时，下载只能尝试平台现有的合并格式；没有可用格式仍可能失败，本地转写也需要这两个工具。

macOS / Linux 使用时，将 `.venv/Scripts/python.exe` 换成 `.venv/bin/python`、`npm.cmd` 换成 `npm`，配置复制命令使用对应终端的写法。

## 第一步：克隆项目

已有本地代码时直接打开当前目录。需要从远程获取时，把下方地址替换成当前 SaveAny 版本的仓库地址。

```powershell
git clone "替换为当前 SaveAny 项目的仓库地址" video-downloader
cd video-downloader
```

原始参考仓库用于学习来源对照，不包含本项目后续增加的全部功能。

## 第二步：获取 API Key

只有 AI 生成功能需要 DeepSeek Key。视频解析和下载可以先不配置模型；Stripe 为可选测试支付。

### DeepSeek 配置

在 [DeepSeek 开放平台](https://platform.deepseek.com/)创建 API Key，保存到本机配置。摘要、导图、问答和翻译会调用模型，费用以提供商账户为准，应用内每日免费次数不代表提供商免收费用。

### 可选：Stripe 配置

需要体验会员支付时，在 [Stripe Dashboard](https://dashboard.stripe.com/) 使用测试环境，准备以下配置：

- `STRIPE_SECRET_KEY`：以 `sk_test_` 开头的测试私钥
- `STRIPE_PRICE_ID_VIP_30D`：一次性 CNY 990 分的有效 Price，套餐为 ¥9.9 / 30 天，不自动续费
- `STRIPE_WEBHOOK_SECRET`：本地监听输出的 `whsec_...`，不能用 API 私钥替代

安装 [Stripe CLI](https://docs.stripe.com/stripe-cli) 后，在单独终端登录并保持监听：

```powershell
stripe login
stripe listen --forward-to http://127.0.0.1:8000/api/billing/webhook
```

暂不配置 Stripe 不影响下载与 AI；页面会明确显示无法购买。

## 第三步：配置环境变量

从模板创建 `backend/.env`，已有文件不覆盖。后端密钥只保存在本机，不发送到聊天或提交到仓库。

```powershell
if (!(Test-Path backend/.env)) { Copy-Item backend/.env.example backend/.env }
notepad backend/.env
```

首次配置 JWT 密钥时运行下面命令，将输出填入 `JWT_SECRET`，已有密钥保持不变。

```powershell
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

| 字段 | 要求 | 用途 |
|------|------|------|
| JWT_SECRET | 必填，至少 32 字节的随机值 | 登录签名，缺少有效配置时后端无法启动 |
| DATABASE_PATH | 默认 backend/data/app.db | SQLite 数据文件，相对路径按项目根目录解析 |
| DEEPSEEK_API_KEY | AI 功能需要 | 摘要、导图、问答和翻译 |
| DEEPSEEK_BASE_URL / DEEPSEEK_MODEL | 默认 https://api.deepseek.com / deepseek-flash | 模型接口与型号 |
| STRIPE_SECRET_KEY / STRIPE_WEBHOOK_SECRET / STRIPE_PRICE_ID_VIP_30D | 测试支付需要 | 私钥、回调签名和一次性价格 |
| PAYMENT_MODE / PAYMENT_LIVE_ENABLED | 默认 test / false | 使用测试环境，不启用正式收款 |
| FRONTEND_URL | 模板为 http://127.0.0.1:5173 | 支付回跳地址 |
| CORS_ORIGINS | 默认 localhost 与 127.0.0.1 的 5173 来源 | HTTP 与 WebSocket 白名单 |
| ASR_ENABLED / ASR_MODEL_DIR | 默认关闭，模型目录为 backend/models/faster-whisper-small | 可选本地语音转写 |

保留模板中其余默认值即可。`.env` 已被 Git 忽略，配置变化后需要重启后端。

## 第四步：安装依赖

后端使用项目虚拟环境，前端根据锁文件安装依赖。直接调用虚拟环境里的 Python，无需激活脚本或修改 PowerShell 执行策略。

**后端依赖：**

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r backend/requirements.txt
```

**前端依赖：**

```powershell
cd frontend
npm.cmd ci
cd ..
```

下载较慢时，可为本次安装指定镜像：

```powershell
.venv/Scripts/python.exe -m pip install -r backend/requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
cd frontend
npm.cmd ci --registry=https://registry.npmmirror.com
cd ..
```

## 第五步：初始化数据库

本项目使用 SQLite，无需安装独立数据库服务。后端启动时自动创建账号、会话、额度、历史、任务、字幕和订单等数据表。

- 首次运行在 `DATABASE_PATH` 指定位置创建数据库
- 已有数据库先备份，再按版本升级，保留账号、用量和成功结果
- 不删除数据库处理登录或升级问题；手动备份使用 `.venv/Scripts/python.exe -m backend.migrations backup`

## 第六步：启动项目

打开两个位于项目根目录的终端，分别启动后端和前端。后台队列按单后端进程运行，不同时启动两份服务指向同一库和下载目录。

**终端 1：后端**

```powershell
.venv/Scripts/python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload --reload-dir backend
```

看到 `Application startup complete` 和 `http://127.0.0.1:8000` 表示启动成功。

**终端 2：前端**

```powershell
cd frontend
npm.cmd run dev
```

看到 Vite 输出 `http://127.0.0.1:5173/` 后，在浏览器打开该地址。前端端口固定，占用时不会自动切换。

## 第七步：访问项目

游客可以先解析和下载，登录后再使用 AI 和个人功能。解析结果、可用格式与字幕均以实际视频和平台返回为准。

1. 粘贴自己有权访问的视频链接，点击解析，查看标题、封面和可用格式
2. 选择格式下载，文件交给浏览器后查看下载列表
3. 注册并登录，已有总结免费恢复；无结果且额度可用时生成摘要和导图
4. 切换字幕、导图和问答，体验导出与连续追问

| 入口 | 功能 |
|------|------|
| `/history` | 下载与总结历史、保存结果和本人删除 |
| `/queue` | 每批最多 10 条链接，真实进度、取消、下载重试与文件领取 |
| `/billing` | 套餐、服务端会员权益和本人订单 |
| `/guide/` | 公开使用说明、额度和常见问题 |

免费账号每天总结 3 次、问答 10 次、翻译 3 次、转写 60 分钟，四项独立、北京时间零点恢复。完整成功才计量，失败或完成前取消释放预占；主动重新总结成功才再计次，失败保留旧结果。

### 可选：本地转写

没有平台字幕时可以主动转写。安装依赖并显式准备模型，再将 `ASR_ENABLED` 改为 `true`，重启后端。

```powershell
.venv/Scripts/python.exe -m pip install -r backend/requirements-asr.txt
.venv/Scripts/python.exe -m backend.transcriber prepare-model
```

保留正确的 `ASR_MODEL_DIR`，当前固定 small / CPU / int8，模型约 486 MB。单条最多 30 分钟，普通请求不自动下载模型；成功后先展示字幕，用户再决定是否总结。

### 可选：Docker 启动

安装并启动 Docker，准备好 `backend/.env`，再从项目根目录执行：

```powershell
docker compose build
docker compose up -d
docker compose ps
```

访问 http://127.0.0.1:8080 。容器使用独立数据卷，不自动合并本机库；可选 ASR、代理和备份导入见[扩展运行指南](./【剩余扩展】本地运行与验收.md)。

### 可选：生产页面预览

在新终端从项目根目录构建并预览，查看首页和公开指南的 HTML 正文。

```powershell
cd frontend
npm.cmd run build
npm.cmd run preview
```

访问终端显示的地址，默认 http://127.0.0.1:4173/ 。预览用于检查产物，完整业务使用 5173 开发入口或 8080 Docker 入口；正式域名配置见[SEO 与 GEO 运行指南](./SEO与GEO运行指南.md)。

## 常见问题

遇到问题先看终端和页面的具体提示，按下列情况处理。反馈时提供输入、操作步骤和错误，不发送密钥。

### Q1：下载没有声音或画质较低？

确认 `ffmpeg -version` 与 `ffprobe -version` 可用。分离音视频需要合并，缺少 ffmpeg 时只能尝试现成的合并格式；清晰度仍受源视频限制。

### Q2：部分平台无法解析？

先检查链接是否公开、权限和网络是否可用。确认属于解析器版本问题后，可运行 `.venv/Scripts/python.exe -m pip install --upgrade yt-dlp` 并重启后端，检查解析和下载；项目依赖文件保留已锁定版本。

### Q3：后端提示环境变量错误？

确认 `backend/.env` 存在，`JWT_SECRET` 为至少 32 字节的随机值。缺 DeepSeek Key 只影响模型生成，不阻止解析和下载。

### Q4：8000 或 5173 端口被占用？

先确认是否已启动过本项目。Windows 可用 `Get-NetTCPConnection -LocalPort 8000,5173 -State Listen` 查看；停止本项目时回到对应终端按 `Ctrl+C`，不要直接结束其他程序。

### Q5：接口或 WebSocket 出现跨域错误？

从 http://127.0.0.1:5173 访问。更换端口时同步调整 `API_PROXY_TARGET` 和后端 `CORS_ORIGINS`，具体示例见扩展运行指南。

### Q6：抖音链接下载失败？

检查分享链接、视频权限和网络，平台可能限流或调整接口。不能保证所有链接可用；确认是解析器问题后再按 Q2 升级。

### Q7：测试付款后没有会员？

检查三项 Stripe 配置、一次性 CNY 990 分 Price、`PAYMENT_MODE=test` 与正确的 `FRONTEND_URL`。保持 CLI 监听，将本次 `whsec_...` 写入配置并重启后端，测试使用官方测试付款方式；页面回跳不直接开通会员。

### Q8：依赖安装失败？

确认 Python 和 Node.js 版本符合要求，Python 安装命令使用本项目 `.venv`。网络超时可用第四步的镜像，编译类错误按终端缺失的工具处理。

### Q9：PowerShell 拦截 npm 或虚拟环境脚本？

使用 `npm.cmd` 和 `.venv/Scripts/python.exe`，无需修改执行策略。路径含空格或中文时，确认当前目录正确。

### Q10：浏览器能打开，后端却提示不是公网地址？

本机代理可能将公网域名解析为 `198.18.x.x`。仅在确认使用 Fake-IP 时，在启动后端的终端设置 `$env:ALLOW_PROXY_FAKE_IP = 'true'` 再启动；该兼容默认关闭，不用于访问内网地址。

## 停止项目

PowerShell 方式在对应终端按 `Ctrl+C`；Docker 使用 `docker compose down` 保留数据卷，不加 `-v`。账号、用量和成功结果继续保存，关闭网页不会取消后台任务，需要时先在队列中取消。
