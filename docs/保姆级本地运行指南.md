# 🚀 保姆级本地运行指南

本文档手把手教你在本地跑起来 AI 万能视频下载总结器的完整前后端，**零基础也能跟着做**。

以下命令以 **Windows PowerShell** 为例，除明确进入 `frontend` 的步骤外，都在项目根目录 `video-downloader` 执行。已经打开本项目的同学，可以跳过克隆，保留已有配置和数据库继续使用。



## 前置要求

| 工具 | 版本要求 | 检查命令 | 安装方式 |
|------|----------|----------|----------|
| Python | 3.11 或更新的兼容版本 | `python --version` | [官网下载](https://www.python.org/downloads/) |
| Node.js | ≥ 22.12 | `node -v` | [官网下载](https://nodejs.org/en)（选择符合版本要求的 LTS 版本） |
| npm | 随兼容版本的 Node.js 安装 | `npm.cmd -v` | 随 Node.js 一起安装 |
| ffmpeg | 任意 | `ffmpeg -version` | [官网下载](https://ffmpeg.org/download.html) 或 `brew install ffmpeg`（macOS） |
| Git | 任意 | `git --version` | [官网下载](https://git-scm.com/) |

💡 关于 ffmpeg：ffmpeg 用于合并视频和音频流（如 YouTube 高清视频的画面和声音是分开的）。如果不安装，项目仍可运行，但下载高清视频时会降级为低画质单一格式。**强烈建议安装。**

💡 本地转写还需要 `ffprobe` 检查音轨时长，安装后运行 `ffprobe -version` 确认它也已加入 PATH。macOS / Linux 使用时，将下文的 `.venv/Scripts/python.exe` 换成 `.venv/bin/python`、`npm.cmd` 换成 `npm`，配置复制命令使用对应终端的写法。

## 第二步：获取 API Key

## 第三步：配置环境变量

```powershell
if (!(Test-Path backend/.env)) { Copy-Item backend/.env.example backend/.env }
notepad backend/.env
```

用任意文本编辑器打开 `backend/.env` 文件，填入你的配置：

```env
# ✅ AI 功能必填 - DeepSeek API Key，用于总结、导图、问答和翻译
DEEPSEEK_API_KEY=sk-你的真实key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash

# ✅ 必填 - JWT 密钥，用于用户登录认证
# 本地开发同样要求至少 32 字节的随机值，已有密钥保持不变
JWT_SECRET=替换为下一条命令生成的随机值
DATABASE_PATH=backend/data/app.db

# 🔧 选填 - Stripe 支付配置（不配置不影响核心功能）
STRIPE_SECRET_KEY=sk_test_你的stripe密钥
STRIPE_WEBHOOK_SECRET=whsec_你的webhook密钥
STRIPE_PRICE_ID_VIP_30D=price_你的价格id
PAYMENT_MODE=test
PAYMENT_LIVE_ENABLED=false

# 🔧 选填 - 前端 URL，Stripe 支付完成后跳转地址
FRONTEND_URL=http://127.0.0.1:5173
```

首次配置时，在项目根目录运行下面命令，将输出填入 `JWT_SECRET`。已有密钥不需要重新生成，改完配置后需要重启后端。

```powershell
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

| 字段 | 必填 | 用途 |
|------|------|------|
| `DEEPSEEK_API_KEY` | ✅ AI 功能必填 | 生成视频总结、思维导图、AI 问答和翻译；不填仍可解析和下载 |
| `DEEPSEEK_BASE_URL` / `DEEPSEEK_MODEL` | 🔧 默认即可 | 默认使用 DeepSeek 兼容接口及 `deepseek-flash`，已有配置保持不变 |
| `JWT_SECRET` | ✅ 必填 | 用户登录 Token 的签名密钥，必须至少 32 字节的随机值 |
| `DATABASE_PATH` | 🔧 默认即可 | 默认 `backend/data/app.db`，相对路径按项目根目录解析 |
| `STRIPE_SECRET_KEY` | 🔧 选填 | Stripe 支付 API 密钥，不填则支付功能不可用 |
| `STRIPE_WEBHOOK_SECRET` | 🔧 选填 | Stripe Webhook 签名验证密钥 |
| `STRIPE_PRICE_ID_VIP_30D` | 🔧 选填 | Stripe 一次性 30 天会员价格 ID，CNY 990 分 |
| `PAYMENT_MODE` / `PAYMENT_LIVE_ENABLED` | 🔧 默认即可 | 本地使用 `test` / `false`，不启用正式收款 |
| `FRONTEND_URL` | 🔧 选填 | 支付完成后跳转地址，模板为 `http://127.0.0.1:5173` |
| `CORS_ORIGINS` | 🔧 默认即可 | 默认允许 localhost 与 127.0.0.1 的 5173 来源，WebSocket 同样检查 |
| `ASR_ENABLED` / `ASR_MODEL_DIR` | 🔧 选填 | 本地语音转写开关和模型目录，启用前需单独安装依赖、准备模型 |

⚠️ **注意**：`.env` 文件包含敏感信息，已被 `.gitignore` 排除，不会提交到代码仓库。

## 第五步：初始化数据库

本项目使用 **SQLite**，**无需手动安装任何数据库软件**。

后端服务启动时会自动完成以下操作：

1. 在 `backend/data/` 目录下创建 `app.db` 数据库文件
2. 自动建表（`users` 用户表、`auth_sessions` 会话表、额度记录、成功总结、下载历史、后台任务、字幕结果及 `payment_orders` 订单表）
3. 已有数据库按版本升级，先创建一致备份，再保留原账号、用量和成功结果增加新结构

💡 不要通过删除数据库解决登录或升级问题。需要手动备份时，在项目根目录运行 `.venv/Scripts/python.exe -m backend.migrations backup`，命令会输出备份路径。

## 常见问题

### Q1：`ffmpeg` 未安装，下载视频报错或画质很低？

**原因**：高清视频的画面和声音是分开的，需要 ffmpeg 合并。

**解决**：
```bash
# macOS
brew install ffmpeg

# Ubuntu / Debian
sudo apt install ffmpeg

# Windows：从 https://ffmpeg.org/download.html 下载，解压后将 bin 目录加入 PATH
```

### Q2：`yt-dlp` 版本过低，解析视频失败？

**现象**：部分视频解析失败，报错 `Unable to extract` 或 `Unsupported URL`。

**解决**：
```powershell
.venv/Scripts/python.exe -m pip install --upgrade yt-dlp
```

💡 当前版本已在 `backend/requirements.txt` 锁定。升级前先确认是否属于权限、平台限制或网络问题；升级后重启后端并检查解析和下载。

### Q3：后端启动报环境变量未设置？

**原因**：`backend/.env` 未创建，或 `JWT_SECRET` 为空、少于 32 字节。

**解决**：按第三步复制配置模板，并生成足够长的随机 JWT 密钥。`DEEPSEEK_API_KEY` 缺失只影响 AI 生成，不阻止解析和下载；填写密钥后重启后端。

### Q4：端口 8000 或 5173 被占用怎么办？

**解决**：

先确认是否已启动过本项目，已有服务可以直接使用；需要停止时回到对应终端按 `Ctrl+C`。

```powershell
# Windows PowerShell：查看监听端口的进程编号
Get-NetTCPConnection -LocalPort 8000,5173 -State Listen
```

```bash
# 查看占用端口的进程
lsof -i :8000    # macOS / Linux
```

💡 前端固定使用 5173，占用时不会自动换端口。不要直接终止不属于本项目的进程；需要隔离端口时，按[扩展运行指南](./【剩余扩展】本地运行与验收.md)同时调整后端代理和来源白名单。

### Q5：前端请求后端接口返回 CORS 错误？

**解决**：确保通过 `http://127.0.0.1:5173` 访问前端页面。前端会自动将 `/api` 请求通过 Vite 代理转发到后端，默认后端地址为 `http://127.0.0.1:8000`。后端默认只允许 localhost 和 127.0.0.1 的 5173 来源；使用其他前端端口时需同步设置 `CORS_ORIGINS`，WebSocket 同样检查来源。

### Q6：下载抖音视频失败？

**解决**：

1. 确保使用的是抖音分享链接（如 `https://v.douyin.com/xxx`）
2. 检查网络是否正常，抖音接口可能有频率限制
3. 确认属于解析器版本问题后，按 Q2 升级 yt-dlp 并重启后端

### Q7：Stripe 支付功能测试不成功？

**解决**：

1. 确保 `.env` 中 `STRIPE_SECRET_KEY`、`STRIPE_WEBHOOK_SECRET`、`STRIPE_PRICE_ID_VIP_30D` 都已填写，同时确认 `PAYMENT_MODE=test` 及 `FRONTEND_URL` 对应当前前端入口
2. 确保 Stripe Dashboard 处于「测试模式」
3. 测试支付时使用 Stripe 提供的测试卡号：`4242 4242 4242 4242`
4. 本地测试 Webhook 需运行 Stripe CLI：
   ```bash
   stripe listen --forward-to http://127.0.0.1:8000/api/billing/webhook
   ```

5. 将本次监听输出的 `whsec_...` 填入配置后重启后端，保持 Stripe CLI 终端运行；价格需为一次性 CNY 990 分，会员以服务端收到有效付款回调后为准

### Q8：`pip install` 安装依赖报错？

**常见情况**：

- **bcrypt 编译失败**：安装 C 编译工具。macOS 运行 `xcode-select --install`
- **Python 版本过低**：使用 Python 3.11 或更新的兼容版本，并确认安装命令指向本项目 `.venv`
- **网络超时**：使用国内镜像 `-i https://pypi.tuna.tsinghua.edu.cn/simple`

### Q9：Windows 系统运行终端命令报错？

**解决**：本文命令以 PowerShell 为例。`npm.ps1` 被执行策略拦截时使用 `npm.cmd`，Python 使用 `.venv/Scripts/python.exe`，不需要修改执行策略。路径包含空格或中文时，先确认终端当前目录是项目根目录。

### Q10：视频链接提示不是公网地址，但浏览器可以访问？

**原因**：本机代理可能把公网域名解析成 `198.18.x.x` Fake-IP，触发地址检查。

**解决**：仅在确认使用这种代理时，在启动后端的终端设置 `$env:ALLOW_PROXY_FAKE_IP = 'true'`，再执行第六步的后端启动命令。该兼容默认关闭，不能用于访问 localhost 或内网视频地址；详细说明见 [README 快速运行说明](../README.md#四快速运行)。



## 停止项目

在各终端窗口按 `Ctrl + C` 即可停止前后端服务。

数据库文件（`backend/data/app.db`）会保留，下次启动时数据不会丢失。

💡 Docker 方式在项目根目录运行 `docker compose down` 停止，普通停止保留数据卷；不要加 `-v`，避免删除账号、额度和结果。关闭网页不会停止后台任务，需要时先在队列中取消。
