# 万能视频下载网站 - 需求分析文档

## 1. 项目背景

用户有从各平台下载保存视频到本地的需求，但很多平台不支持直接下载、或限制较多（清晰度限制、不支持批量下载等）。本项目旨在提供一个统一的、跨平台的万能视频下载工具网站。

## 2. 目标用户

- 需要下载在线视频到本地保存的个人用户
- 需要批量采集视频素材的内容创作者
- 需要在移动端随时下载视频的用户
- 想快速了解长视频内容、提升学习效率的用户

## 3. 核心功能需求

### 3.1 视频解析（P0）

- 用户粘贴视频链接，系统自动解析视频信息
- 展示视频标题、缩略图、时长、上传者、平台来源
- 列出所有可用的格式和清晰度选项

### 3.2 视频下载（P0）

- 用户选择清晰度/格式后，点击下载
- 支持两种下载模式：
  - **直链模式**：解析出视频直链，浏览器直接下载（不占服务器资源）
  - **服务端代理模式**：服务端下载后提供下载链接（兼容有防盗链的平台）
- 自动选择最优下载模式

### 3.3 多平台支持（P0）

- 基于 yt-dlp 开源项目，支持 1800+ 平台
- 包括但不限于：YouTube、Bilibili、抖音、TikTok、Twitter/X、Instagram 等
- 实际可用性受视频权限、平台限制和网络环境影响，清晰度以解析返回的可用格式为准

### 3.4 移动端适配（P1）

- 响应式设计，手机浏览器也能正常使用
- 触屏友好的交互设计

### 3.5 付费功能（P2，已实现）

- 免费版：游客可解析和单条下载；登录后可使用批量下载、字幕导出及每日免费 AI 额度
- VIP 版：提高 AI 每日额度，总结 30 次、问答 100 次、翻译 20 次、转写 240 分钟；下载能力与免费账号相同
- 支付方式：接入 Stripe Checkout，当前已完成测试环境支付验证；测试商品为 ¥9.9 / 30 天，不自动续费，缺少支付配置时不开放购买，正式收款尚未验证
- 会员开通以服务端确认付款为准，重复支付回调不重复延长权益；到期后恢复免费额度，当天已用额度不清零

### 3.6 AI 视频总结（P1，已实现）

- 用户登录后进入视频解析结果页，优先恢复已保存结果；没有保存结果时自动触发 AI 分析，也可点击「重新总结」主动生成
- **总结摘要**：AI 自动生成视频概述、内容大纲、核心知识要点、一句话总结，使用 @tailwindcss/typography 精美排版
- **字幕文本**：展示带时间戳的完整字幕列表，支持展开/收起，支持下载字幕文件（SRT / VTT / TXT 三种格式）
- **思维导图**：AI 生成结构化内容，前端渲染为可交互的思维导图，支持全屏展示，支持下载高清 PNG（4K+）和 SVG 矢量图
- **AI 问答**：用户可针对视频内容提问，AI 基于字幕上下文回答，支持多轮对话
- 字幕获取策略：优先提取平台自带字幕（人工字幕 > 自动字幕），B 站通过专用 API 获取 CC 字幕
- AI 能力：接入 DeepSeek 大模型，流式输出（SSE），实时展示生成过程
- 总结和问答基于字幕前 15000 字符，超长内容在页面提示分析范围；没有字幕时不猜测视频内容
- 同账号、同链接、同总结语言的成功结果可免费恢复，刷新、退出重登或重启后端不重复生成；重新总结失败保留上次成功结果

### 3.7 扩展功能（P2，已实现）

- 字幕翻译（已实现）：支持将本人已保存的总结字幕或转写字幕翻译为简体中文、英语、日语，保留时间戳，支持 SRT / VTT / TXT 导出；每次最多 20000 字符、1000 段，超出时明确提示，不截断翻译
- 语音转写（已实现）：无平台字幕时，用户可主动使用本地 Whisper 模型生成字幕；单条视频最多 30 分钟，转写后由用户决定是否生成总结；模型和依赖需单独准备
- 下载历史记录（已实现）
- 批量下载（已实现）
- 翻译和转写成功结果可免费恢复，失败或取消保留原文和上次成功内容，不计成功额度

### 3.8 用户系统与 AI 额度（P1，已实现）

- 支持邮箱注册、登录和退出，登录状态刷新后可恢复；退出撤销当前会话，不影响其他独立登录会话
- 游客可解析和单条下载；AI 总结、问答、翻译、转写、个人历史和后台队列需要登录
- 免费账号每日总结 3 次、问答 10 次、翻译 3 次、转写 60 分钟，四项额度独立，按服务端北京时间零点恢复
- 完整成功才计量，失败、完成前取消或任务过期释放预占；并发请求不能超用，已保存结果免费恢复
- 账号之间的数据相互隔离，退出或切换账号后清空页面中的旧账号内容

### 3.9 个人历史（P2，已实现）

- 登录后查看本人的下载与总结历史，支持分页、打开详情和单条删除
- 下载历史保存原始链接、格式、时间和处理状态，不保存视频文件；「已交给浏览器」不代表文件已保存到用户电脑
- 总结历史直接打开保存的字幕、摘要和导图，不依赖重新解析视频，不调用模型或扣次
- 删除总结同时移除该份免费恢复内容及关联译文，不返还已用额度；删除下载历史不影响用户电脑中的文件

### 3.10 后台队列与下载进度（P2，已实现）

- 每批最多提交 10 条单视频链接，同批相同链接和格式自动去重；支持将单条视频加入后台下载
- 关闭页面或断网后任务继续执行，支持查看状态、取消，以及失败或取消后的手动重试；单项失败不影响其他任务
- WebSocket 推送真实下载字节、速度、预计剩余时间和处理阶段，断线后恢复快照，不可用时回退轮询；未知总量和合并阶段不显示虚构百分比
- 后台下载文件保留 24 小时，仅本人可领取；过期提示重新下载，单文件最多 2 GiB，队列临时文件预算 10 GiB
- 服务重启后保留排队任务，执行中的任务标记中断，由用户决定是否重试

### 3.11 搜索与公开使用说明（P1，已实现）

- 首页及公开使用指南 `/guide/` 提供无需运行 JavaScript 即可读取的产品介绍、使用步骤和常见问题
- 各页面配置标题、描述和分享信息，公开问答提供结构化数据及 `llms.txt` 资料入口
- 配置正式域名后生成公开页面的规范网址和网站地图；未配置域名时默认不索引，不生成虚构网址
- 工作台、个人历史、队列与会员订单页面始终不索引，不将私人内容写入公开页面；实际收录和 AI 引用待上线后观察

## 4. 非功能需求

- **性能**：视频解析响应时间 < 10s
- **可用性**：简洁易用的 UI，新用户无需学习即可使用
- **安全性**：密码使用哈希保存，个人数据按账号隔离；外部视频地址限制为公网 HTTP / HTTPS，临时文件定期清理
- **数据保存**：账号、额度、历史和成功文本结果持久保存；单条下载响应结束清理，后台文件保留 24 小时，转写临时音频用完即清理
- **兼容性**：支持 Chrome、Firefox、Safari、移动端浏览器

## 5. 技术约束

- 以 Python 为主要技术栈
- 核心下载能力依赖 yt-dlp 开源项目
- 使用 SQLite 本地数据库，保持轻量，无需独立数据库服务；升级自动备份并保留已有数据
- 前后端分离架构
- 后台队列采用单实例、单进程运行；支持 Docker Compose 本地部署，转写依赖和模型按需启用
