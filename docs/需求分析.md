# 万能视频下载网站 - 需求分析文档

## 1. 项目背景

用户希望保存不同平台的视频，并在观看长视频前快速了解内容。本项目提供统一的视频链接入口，将解析、下载、字幕和 AI 内容整理放在同一使用流程中。

## 2. 目标用户

- 需要离线观看或备份授权视频的个人用户
- 需要批量整理视频素材的内容创作者
- 希望用摘要、导图和问答辅助学习的用户
- 需要在手机浏览器中随时处理视频的用户

## 3. 核心功能需求

### 3.1 视频解析（P0）

用户粘贴链接后查看实际视频信息，再选择需要下载的格式。

- 展示标题、封面、时长、上传者和平台来源
- 列出可用清晰度、音视频格式和已知文件大小
- 平台未提供的信息如实显示未知，解析失败后可以重试

### 3.2 视频下载（P0）

系统优先使用浏览器直链，无法直接获取时回退到服务端处理。

- **直链模式**：浏览器获取视频文件，不占服务器下载带宽
- **代理模式**：服务端处理防盗链、分段视频或音视频合并，再提供文件
- 用户选择格式后下载，页面显示准备、交接或失败状态
- 文件交给浏览器后提示查看下载列表，不声称已保存到用户磁盘

### 3.3 多平台支持（P0）

下载能力基于 yt-dlp，并为抖音提供专用解析模块。

- 支持 Bilibili、YouTube、抖音、TikTok、Twitter/X、Instagram 等平台
- 平台覆盖以 yt-dlp 支持范围为基础，具体链接受权限、网络和平台限制影响
- 清晰度和格式以源视频实际返回的内容为准

### 3.4 移动端适配（P1）

手机和平板使用相同功能，页面布局随可用空间调整。

- 桌面端并排展示视频与 AI 内容，窄屏改为上下排列
- 输入框、按钮、标签和导出操作适合触屏使用
- 主要入口支持键盘操作、清晰焦点和可读错误提示

### 3.5 会员与支付（P2）

会员提高 AI 使用额度，游客下载和免费账号已有功能继续保留。

- 免费登录用户可使用批量下载、字幕导出和每日 AI 额度
- 当前测试商品为 ¥9.9 / 30 天，一次购买，不自动续费
- Stripe 服务端确认付款后授予权益，重复回调不重复延长
- 缺支付配置时不开放购买；会员到期恢复免费上限，当天已用量不清零
- 正式收款尚未验证，页面回跳参数不能直接开通会员

### 3.6 AI 视频总结（P1）

登录后先恢复已保存结果，无结果且额度可用时自动生成，也可主动重新总结。

- **总结摘要**：视频概述、内容大纲、核心要点和一句话总结，支持 Markdown 排版与复制
- **字幕文本**：时间戳分段、展开/收起和 SRT / VTT / TXT 下载
- **思维导图**：节点折叠、缩放、拖拽和全屏，导出完整 SVG 和高清 PNG（4K+）
- **视频问答**：基于字幕连续追问，流式展示回答，缺少的信息明确说明
- 平台字幕优先使用人工字幕，再使用自动字幕；B 站优先通过专用 API 提取
- 摘要、导图和问答分析字幕前 15000 字符，页面提示范围，完整字幕仍可导出
- 同账号、同链接、同总结语言的成功结果免费恢复；重新生成失败保留上次成功内容

### 3.7 字幕翻译与语音转写（P2）

字幕处理保留原文，用户可以按需翻译，或为没有平台字幕的视频主动生成转写字幕。

- **字幕翻译**：本人已保存的总结/转写字幕可翻译为简体中文、英语和日语，沿用时间戳并支持导出
- **长度限制**：每次完整原文最多 20000 字符、1000 段，超出时明确拒绝，不截断翻译
- **语音转写**：显式启用本地 small / CPU / int8 模型，免费和 VIP 单条视频均最多 30 分钟
- 已有平台字幕时不运行转写；转写成功先交付字幕，再由用户决定是否总结
- 翻译和转写成功结果可免费恢复，失败或取消不覆盖旧结果、不计成功用量

### 3.8 用户系统与 AI 额度（P1）

邮箱账号用于保存个人资料和管理 AI 额度，游客仍可解析及单条下载。

- 支持注册、登录、刷新恢复和真实退出，账号之间的数据相互隔离
- AI、个人历史和后台任务需要登录，退出或换号后清空旧账号页面内容
- 四项额度独立，服务端北京时间零点恢复，完整成功才计量
- 执行前预占防止并发超用，失败、完成前取消或过期释放预占

| 能力 | 免费账号 | VIP |
|------|----------|-----|
| 每日总结 | 3 次 | 30 次 |
| 每日问答 | 10 次 | 100 次 |
| 每日翻译 | 3 次 | 20 次 |
| 每日转写 | 60 分钟 | 240 分钟 |

### 3.9 个人历史（P2）

用户可以找回处理过的视频，并直接阅读已经保存的总结。

- 下载与总结分类展示，支持分页、详情和本人单条删除
- 下载历史只保存链接、格式、时间和状态，不长期保存视频
- 总结详情直接读取字幕、摘要和导图，不依赖原平台、不调用模型或扣次
- 删除总结同时移除该份恢复内容和关联译文，不返还额度；删除下载历史不删除用户电脑文件

### 3.10 后台队列与真实进度（P2）

用户一次提交多个链接，或把单条下载转入后台，稍后查看和领取结果。

- 每批最多 10 条单视频链接，同批相同 URL + 格式去重，单项失败不影响其他任务
- 支持状态查看、显式取消和下载任务手动重试，关闭页面或断网不取消任务
- WebSocket 推送真实字节、速度和阶段，重连恢复快照，不可用时回退轮询
- 未知总量和合并阶段不显示虚构百分比
- 后台单文件最多 2 GiB，临时空间预算 10 GiB；文件准备后保留 24 小时，仅本人可领取
- 重启保留排队项，执行中项标记中断，用户决定是否重试

### 3.11 搜索与公开使用说明（P1）

公开页面介绍真实功能和使用条件，个人内容不进入搜索索引。

- 首页和 `/guide/` 在构建时输出正文，不运行 JavaScript 也能阅读
- 配置标题、描述、分享信息、结构化问答和 `llms.txt`
- 没有正式域名时默认不索引；配置正式站点地址后生成公开页面的规范网址和网站地图
- 工作台、历史、队列与订单始终不索引，不将个人链接或生成内容写入公开资料
- 实际搜索收录和 AI 引用需上线后观察

## 4. 非功能需求

功能应保持易用、可恢复，页面状态与服务端实际结果一致。

- **性能**：解析目标为 10 秒内；平台响应较慢时持续显示状态，失败可重试
- **可用性**：首次使用可直接解析下载，错误提示说明下一步操作
- **安全性**：密码哈希保存，个人接口检查归属，输入视频地址限制为公网 HTTP / HTTPS
- **数据保存**：账号、额度和成功文本持久保存；单条下载响应结束清理，后台媒体保留 24 小时，转写临时音频用完即清理
- **兼容性**：面向 Chrome、Firefox、Safari 及移动端浏览器，实际表现按运行环境检查

## 5. 技术约束

项目保持前后端分离和本地轻量部署，按需启用模型与支付能力。

- Python + FastAPI 后端，Vue 3 前端，下载依赖 yt-dlp 与 ffmpeg
- SQLite 本地持久化，无需独立数据库服务，升级先备份并保留数据
- 后台队列采用单实例、单后端进程，Docker Compose 为可选运行方式
- 本地转写依赖与模型单独准备，支付默认使用测试环境
