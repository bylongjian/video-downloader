# 万能视频下载网站 - 方案设计文档

## 1. 技术架构

```
┌──────────────────────────────────────────────────────────┐
│                     用户浏览器                            │
│  ┌─────────────────────────────────────────────────────┐ │
│  │           Vue3 + Vite + Tailwind CSS               │ │
│  │  URL输入 → 解析展示 → 格式选择 → 下载              │ │
│  │                     ↘ AI总结 → 摘要/字幕/导图/问答  │ │
│  └──────────────────────┬──────────────────────────────┘ │
└─────────────────────────┼────────────────────────────────┘
                          │ HTTP API / SSE
┌─────────────────────────┼────────────────────────────────┐
│                  FastAPI 后端                              │
│  ┌──────────────────────┴──────────────────────────────┐ │
│  │  /api/parse      → 解析视频信息                      │ │
│  │  /api/download   → 服务端下载并提供文件              │ │
│  │  /api/direct-url → 获取视频直链                      │ │
│  │  /api/summarize  → AI视频总结（SSE流式）             │ │
│  │  /api/chat       → AI视频问答（SSE流式）             │ │
│  └──────────┬─────────────────────────┬──────────────┘ │
│             │                         │                  │
│  ┌──────────┴──────────┐  ┌───────────┴──────────────┐ │
│  │   yt-dlp 封装层      │  │   AI 总结模块             │ │
│  │   extract_info()     │  │   SubtitleExtractor       │ │
│  │   download()         │  │   → 字幕提取(yt-dlp/B站)  │ │
│  │   get_url()          │  │   VideoSummarizer         │ │
│  │                      │  │   → DeepSeek API 总结/问答 │ │
│  └──────────────────────┘  └────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

扩展模块：

- **用户与数据**：账号认证、AI 额度、个人历史和成功结果通过 SQLite 保存，个人接口按当前会话检查归属
- **后台任务**：批量下载、字幕翻译和语音转写共用持久队列，通过 WebSocket 推送进度，AI 总结与问答继续使用 SSE
- **会员支付**：Stripe Checkout 创建付款会话，服务端验签回调后保存订单与会员权益
- **公开页面**：首页和使用指南在构建时输出完整 HTML，Nginx 提供静态页面并代理 API / SSE / WebSocket

## 2. 技术栈选型

| 层次          | 技术                             | 选型理由                               |
| ------------- | -------------------------------- | -------------------------------------- |
| 前端框架      | Vue 3 + Vite                     | 轻量、上手快、生态成熟                 |
| CSS 框架      | Tailwind CSS                     | 快速构建精美 UI，无需写大量自定义 CSS  |
| Markdown 渲染 | marked + DOMPurify + @tailwindcss/typography | marked 转 HTML，DOMPurify 清理后使用 prose 类排版 |
| 思维导图      | markmap-lib + markmap-view       | 开源成熟，支持 Markdown 输入，交互性好 |
| 后端框架      | FastAPI (0.162.0)                 | 异步高性能、原生 SSE 支持、Python 生态 |
| 核心能力      | yt-dlp                           | 开源下载工具，便于扩展平台解析   |
| AI 大模型     | DeepSeek (deepseek-flash)        | 兼容 OpenAI 协议，通过 openai SDK 调用 |
| 数据库        | SQLite                          | 本地持久化账号、额度、历史及成功结果，无需独立服务 |
| 用户认证      | bcrypt + PyJWT                  | 密码哈希保存，JWT 配合服务端会话撤销登录 |
| 语音转写      | faster-whisper（small / CPU int8） | 本地推理，依赖和模型按需安装            |
| 支付          | Stripe Checkout                 | 托管付款页面，服务端验签后授予会员权益  |
| 部署          | Docker Compose + Nginx          | 固定运行环境，持久卷保存数据，代理 API / SSE / WebSocket |

```

Request:
{
    "url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",

```

### 3.4 AI 视频总结（SSE 流式）

```
POST /api/summarize
Content-Type: application/json
Authorization: Bearer <token>

Request:
{
    "url": "https://www.bilibili.com/video/BV1mAAmzqEfP",
    "language": "zh"
}

Response: SSE 事件流 (Content-Type: text/event-stream)
事件类型：
  - subtitle  → 字幕数据（含 segments 时间戳列表和 full_text）
  - summary   → 总结摘要（流式 token，逐字输出）
  - mindmap   → 思维导图 Markdown（一次性返回）
  - quota     → 成功结算后的额度快照
  - done      → 完成信号
  - error     → 错误信息
```

可选参数：`video_title`、`platform` 用于保存历史元信息，`transcript_id` 用于显式选择本人已完成的转写字幕。

```
GET /api/summarize/result?url=<视频原始链接>&language=zh
Authorization: Bearer <token>

Response: 本人已保存的字幕、摘要和导图，无结果时 data 为 null
```

### 3.5 AI 视频问答（SSE 流式）

```
POST /api/chat
Content-Type: application/json
Authorization: Bearer <token>

Request:
{
    "url": "https://www.bilibili.com/video/BV1mAAmzqEfP",
    "question": "这个视频用了什么技术栈？",
    "subtitle_text": ""
}

Response: SSE 事件流 (Content-Type: text/event-stream)
事件类型：
  - answer    → AI 回答（流式 token）
  - quota     → 成功结算后的额度快照
  - done      → 完成信号
  - error     → 错误信息
```

可选参数：`history` 为最近的对话消息列表，每项包含 `role`（user / assistant）和 `content`，用于连续追问；问答正文不持久保存。

### 3.6 用户认证与额度

```
POST /api/auth/register   → 邮箱注册，成功后返回 Token、用户信息及额度
POST /api/auth/login      → 邮箱登录，返回内容同注册

Request:
{
    "email": "user@example.com",
    "password": "example-password"
}

GET  /api/auth/me         → 当前用户与额度
GET  /api/auth/quota      → 总结、问答、翻译、转写四项额度及会员状态
POST /api/auth/logout     → 撤销当前登录会话
Authorization: Bearer <token>（me / quota / logout）
```

### 3.7 个人历史

```
Authorization: Bearer <token>

GET    /api/history?kind=summary&limit=20&cursor=<分页游标>
                                  → 总结历史，kind=download 时返回下载历史
GET    /api/history/{kind}/{id}    → 本人历史详情
DELETE /api/history/{kind}/{id}    → 删除本人记录
POST   /api/history/downloads      → 记录下载链接、标题、平台及格式
POST   /api/history/downloads/{id}/events
                                  → 更新浏览器交接、失败或取消状态
```

### 3.8 批量下载与后台任务

```
POST /api/batches
Content-Type: application/json
Authorization: Bearer <token>

Request:
{
    "request_key": "本次提交的唯一标识",
    "items": [
        {
            "url": "https://www.bilibili.com/video/BV1mAAmzqEfP",
            "format_id": "bestvideo+bestaudio/best"
        }
    ]
}

Response (202): 批次与任务快照，每批最多 10 条

GET  /api/batches/{id}       → 本人批次
GET  /api/tasks              → 本人任务列表，支持筛选与分页
GET  /api/tasks/{id}         → 最新任务快照
GET  /api/tasks/{id}/result  → 已完成的翻译或转写结果
POST /api/tasks/{id}/cancel  → 取消任务
POST /api/tasks/{id}/retry   → 下载任务重试，提交新的 request_key
GET  /api/tasks/{id}/file    → 领取本人已准备好的视频文件
WS   /api/tasks/{id}/progress → 任务快照、状态更新和心跳
```

HTTP 接口需要 Bearer 认证；WebSocket 校验 Origin，连接后 5 秒内发送 `{"type":"authenticate","token":"<token>"}`，不在 URL 中传递 Token。

### 3.9 字幕翻译与语音转写

```
POST /api/subtitles/translate
Content-Type: application/json
Authorization: Bearer <token>

Request:
{
    "request_key": "本次提交的唯一标识",
    "source_kind": "summary",
    "source_id": "本人已保存的总结结果 ID",
    "target_language": "en",
    "force": false
}

POST /api/transcriptions
Content-Type: application/json
Authorization: Bearer <token>

Request:
{
    "request_key": "本次提交的唯一标识",
    "url": "https://www.bilibili.com/video/BV1mAAmzqEfP",
    "language": "auto",
    "force": false
}

Response: 已有成功结果返回 200，否则返回 202 及后台任务

GET    /api/subtitles/translation?source_kind=summary&source_id=<来源ID>&target_language=en
DELETE /api/subtitles/translations/{id}
GET    /api/transcriptions/result?url=<视频原始链接>
DELETE /api/transcriptions/{id}
```

查询和删除同样需要认证。翻译来源支持 `summary` / `transcription`，目标语言支持 `zh` / `en` / `ja`；`force=true` 表示主动重新生成，成功后才再次计量。

### 3.10 会员与支付

```
GET /api/billing/plans      → 公开套餐、权益及支付配置状态

POST /api/billing/checkout
Content-Type: application/json
Authorization: Bearer <token>

Request:
{
    "request_key": "本次提交的唯一标识",

```

## 4. 下载模式策略

系统自动选择最优下载模式：

1. **优先尝试直链模式**：调用 `/api/direct-url` 获取直链
   - 如果成功且直链可用 → 浏览器直接下载（不占服务器带宽）
2. **回退到代理模式**：如果直链不可用或有防盗链
   - 调用 `/api/download` → 服务端下载后流式传输给用户
3. **后台下载模式**：用户主动选择后台下载或批量提交链接
   - SQLite 保存任务 → 工作线程执行 → 文件准备好后由本人领取，保留 24 小时
   - 全局及同账号最多同时下载 2 个；同账号未完成任务最多 30 个，全局最多 100 个
   - 单文件最多 2 GiB，队列临时文件预算 10 GiB；只使用可监控字节的 HTTP、原生 HLS / DASH 下载路径，其他路径提示改用单条下载
4. **真实进度**：yt-dlp hook 上报字节、总量、速度、预计剩余时间及音视频轨道，WebSocket 按任务版本推送
   - 断线先获取最新快照，再重新订阅；WebSocket 不可用时回退轮询
   - 未知总量、合并和后处理只展示阶段；浏览器直链下载只显示交接状态，不推测磁盘保存结果
5. **取消与恢复**：页面关闭不取消后台任务，用户显式取消后在处理边界停止；重启保留排队任务，执行中任务标记中断，支持下载任务手动重试

后台任务快照保留 30 天，成功文本结果单独保存；文件清理避开活跃任务和正在领取的文件。原单条下载不增加后台队列的登录、大小或并发限制，响应结束后清理临时目录。

## 5. 前端页面设计

### UI 风格参考

参考 ai.codefather.cn/painting 的设计风格：

- 现代简约，蓝白主色调
- 主色 `#1777FF`，背景白色 `#FFFFFF`，浅灰区域 `#F8FAFC`
- 胶囊形按钮（border-radius: 9999px）
- 12px 圆角卡片 + 轻阴影
- 响应式设计，移动端适配
- 当前实现以 `prototypes` 中的 A 舒展版为依据，沿用蓝白配色和卡片布局

### 页面结构

1. **Header**：Logo + 导航 + 登录/退出 + 历史/队列/会员入口
2. **Hero 区域**：大标题 + 副标题 + URL 输入框（解析成功后自动收缩为紧凑搜索条，隐藏 SLOGAN）
3. **视频面板**（解析成功后进入 `/workbench`，左右双栏同屏布局）：
   - **左栏（40%）**：缩略图 + 视频元信息 + 格式选择 + 下载按钮 + 后台下载按钮
   - **右栏（60%）**：AI 总结面板，4 个 Tab（总结摘要 / 字幕文本 / 思维导图 / AI 问答）
   - 游客显示登录引导；登录后先恢复保存结果，无结果且额度可用时自动总结，保留「重新总结」按钮（执行中禁用）
   - 移动端和窄屏回退为上下堆叠布局
4. **功能亮点区**：5 个特性卡片（含 AI 视频总结）
5. **VIP 套餐区**：免费版 vs 高级版
6. **平台展示区**：支持的平台 Logo
7. **Footer**：版权和免责声明
8. **个人历史 `/history`**：下载/总结分类、分页、详情和单条删除；历史总结直接读保存内容，重新下载时由用户显式解析
9. **批量队列 `/queue`**：多链接提交、真实进度、取消/重试、文件领取和已完成字幕结果
10. **会员与订单 `/billing`**：免费/VIP 权益、付款入口和本人订单；回跳后查询服务端状态，不直接开通会员
11. **使用指南 `/guide/`**：公开介绍、操作步骤、能力对比与常见问题，首页和页脚提供入口

## 7. AI 视频总结模块设计

### 7.1 字幕提取策略

```
用户输入 URL
    ├─ B站视频？ → B站专用 API（x/v2/dm/view）获取 CC 字幕 / AI 字幕
    │              ├─ 成功 → 返回字幕
    │              └─ 失败 → 回退到 yt-dlp
    └─ 其他平台 → yt-dlp 提取字幕
                   ├─ 人工字幕（优先：zh > en > ja > ko > 其他）
                   ├─ 自动字幕（同上优先级）
                   └─ 无字幕 → 返回提示
```

字幕格式：VTT / SRT / JSON3 → 解析为结构化分段 `[{start, end, text}, ...]`

### 7.2 AI 调用流程

1. 登录并检查额度，先恢复同账号、同链接、同总结语言的成功结果，无结果或主动重新总结时预占额度
2. 提取字幕文本，或使用用户显式选择的本人转写字幕（模型分析截断至 15000 字符，完整字幕保留）
3. 调用 DeepSeek API（stream=True）流式生成总结摘要
4. 调用 DeepSeek API 生成思维导图 Markdown
5. 通过 SSE 实时推送给前端，完整成功后在同一事务保存结果并结算额度，再发送 quota / done；失败释放预占并保留上次成功结果

### 7.3 SSE 数据传输

- **summary / answer 事件**：token 通过 `json.dumps()` 编码后发送，避免换行符被 SSE 协议拆行导致前端丢失格式
- **前端解析**：严格按照 SSE 规范处理，`data:` 行用 `\n` 拼接，空行触发事件派发，`summary` / `answer` 数据先 `JSON.parse` 解码

### 7.4 前端渲染

- **总结摘要**：marked 解析 Markdown → DOMPurify 清理 HTML → `@tailwindcss/typography` prose 类排版 + 自定义样式覆盖（h1/h2/h3/blockquote/code/pre/table/a 等），流式打字机效果
- **字幕文本**：带时间戳的列表，支持展开/收起，支持下载字幕文件（SRT / VTT / TXT 三种格式）
- **思维导图**：markmap-lib 转换 Markdown → markmap-view 渲染 SVG，支持全屏展示（Fullscreen API），支持下载高清 PNG（4K+）和 SVG 矢量图
- **AI 问答**：对话式 UI，流式输出 + 光标闪烁动画，AI 回复使用 prose 排版

### 7.5 思维导图导出策略

- **PNG 导出**：通过 `<g>` 根节点的 `getBBox()` 获取完整内容边界（不受用户缩放/平移影响）→ 将 `foreignObject` 替换为 SVG `<text>` 元素（规避 Canvas tainted 安全限制）→ 设置完整 `viewBox` + 4x 以上缩放 → Canvas 绘制 → `toBlob()` 导出
- **SVG 导出**：克隆 SVG DOM → 通过 `getBBox()` 重设完整 `viewBox` → 内联 markmap CSS → 序列化为独立 SVG 文件
- **全屏展示**：使用浏览器原生 Fullscreen API，全屏后调用 `markmapInstance.fit()` 自适应

### 7.6 字幕翻译

- **来源**：仅使用本人已保存的总结字幕或转写字幕，原文最多 20000 字符、1000 段，目标语言为简体中文 / 英语 / 日语
- **处理**：提交后台任务 → DeepSeek 按段分批翻译 → 校验返回段 ID 完整一致 → 沿用原时间戳 → 保存译文并结算独立额度
- **恢复**：按账号、来源 ID、原文 hash 和目标语言复用成功结果；主动重新翻译成功才再计次，缺段、失败或取消不覆盖旧译文
- **展示**：字幕标签切换原文/译文，共用 SRT / VTT / TXT 导出

### 7.7 无字幕语音转写

- **启用**：单独安装 `requirements-asr.txt`，通过 `python -m backend.transcriber prepare-model` 显式准备 small 模型，再开启 `ASR_ENABLED`；普通请求不自动下载模型
- **处理**：先检查平台字幕 → 无字幕时获取音轨 → ffmpeg 转换音频并检查实际时长 → 预占转写秒数 → faster-whisper CPU int8 推理 → 保存成功字幕并结算
- **限制**：单转写并发，免费/VIP 单条均最多 30 分钟；已有平台字幕时不运行 ASR，不占转写额度；临时音频完成、失败或取消后清理
- **结果**：返回与平台字幕相同的分段结构，标记 `source=transcription`；本人成功结果免费恢复，用户可显式选择它进行总结或翻译，不自动生成摘要

## 9. 用户与数据设计

### 9.1 登录与会话

- **注册/登录**：邮箱统一去除首尾空白并转小写，密码使用 bcrypt 哈希；JWT 有效期 72 小时，服务端保存会话并检查是否撤销或过期
- **退出/换号**：退出撤销当前会话，前端取消旧请求并清空个人内容；同源标签页同步登录状态，独立登录会话互不影响
- **数据归属**：个人历史、任务、字幕结果与订单均按当前用户查询；浏览器只持久保存 Token，成功文本保存在服务端

### 9.2 AI 额度

- **免费额度**：总结 3 次/日、问答 10 次/日、翻译 3 次/日、转写 60 分钟/日，四项独立
- **VIP 额度**：总结 30 次/日、问答 100 次/日、翻译 20 次/日、转写 240 分钟/日，单条转写仍最多 30 分钟
- **计量规则**：按服务端北京时间零点换日，先预占再成功结算，失败、完成前取消和过期释放；跨日按预占日期计量，转写按实际音频秒数向上取整
- **页面反馈**：显示剩余、处理中占用及恢复时间，刷新、窗口重新激活和换日时向服务端更新；额度查询失败不显示为无限可用

### 9.3 SQLite 数据保存

- **主要数据**：`users` / `auth_sessions` 保存账号和会话，`ai_usage_requests` / `extension_usage_requests` 保存用量，`summary_results` 保存最新成功总结
- **扩展数据**：`download_history`、`task_batches` / `tasks`、`subtitle_translations`、`transcription_results` 分别保存历史、任务、译文与转写；订单、回调和权益分别使用 `payment_orders`、`payment_events`、`membership_grants`
- **恢复与删除**：历史详情直接读取保存结果，不访问视频平台；删除总结同时删除关联译文，删除转写同时删除依赖它的译文，不退还成功额度
- **升级与备份**：默认 `backend/data/app.db`，启动按版本升级并先备份，不删除旧库；Docker 持久化整个 SQLite 目录，临时下载文件使用独立卷

## 10. 会员与支付设计

- **套餐**：当前测试商品为 ¥9.9 / 30 天，不自动续费，提高四项 AI 额度，批量下载和字幕导出同样向免费登录用户开放
- **购买流程**：登录 → 服务端创建订单与 Stripe Checkout → 用户付款 → Stripe 签名回调 → 校验环境、订单、金额、币种及商品 → 同一事务更新订单并授予权益
- **重复与续购**：重复回调不重复授予；有效续购从当前到期时间与付款时间的较晚者增加 30 天，页面回跳仅查询确认结果
- **异常处理**：缺配置时不开放购买，未付款或 Checkout 过期不授予权益；全额退款或争议撤销对应订单权益，部分退款进入人工处理
- **到期规则**：恢复免费上限，当天已用量不清零；合法预占任务可按原授权完成，已有成功结果继续免费恢复
- **当前范围**：Stripe 测试 Checkout、付款与签名回调已验证，正式环境收款及公网发布尚未验证
