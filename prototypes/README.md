# SaveAny 高保真交互原型

## 1. 原型用途

原型用于查看首页、工作台和四个 AI 视图的布局与交互。页面使用演示内容，可独立打开，不需要安装前端依赖、启动后端或配置模型密钥。

- **首页**：链接输入、功能介绍、套餐、操作步骤和常见问题
- **工作台**：视频信息、格式选择、摘要、字幕、导图和问答
- **演示场景**：登录、额度用尽、无字幕、生成失败和模拟付款

实际应用功能与额度见[需求分析](../docs/需求分析.md)，正式运行见[本地运行指南](../docs/保姆级本地运行指南.md)。

## 2. 打开方式

可以直接双击 `index.html`。需要页面跳转、剪贴板或本地存储行为更稳定时，在项目根目录启动 HTTP 预览。

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory prototypes
```

| 地址 | 页面 |
|------|------|
| http://127.0.0.1:4173/index.html | 首页 |
| http://127.0.0.1:4173/workbench.html | 视频工作台 |
| http://127.0.0.1:4173/gallery.html | 桌面、手机与状态图库 |
| http://127.0.0.1:4173/comparison.html | 布局调整前后对比 |

预览服务需自行启动，停止按 `Ctrl+C`。4173 被其他预览占用时，换用空闲端口并同步修改访问地址。

## 3. 体验路径

先通过示例视频查看完整路径，再切换场景观察错误与恢复。所有视频信息和回答均为演示数据。

1. 首页点击示例并解析，进入工作台选择格式，查看模拟下载状态
2. 使用演示账号登录，生成摘要，切换字幕、导图和问答
3. 导出 SRT / VTT / TXT 字幕，操作导图节点、缩放和全屏，导出 SVG / PNG
4. 在“演示场景”切换额度用尽、无字幕、失败和模拟支付结果
5. 更换视频或退出账号，观察内容清理和登录引导

原型的字幕与导图导出会生成真实文件；视频下载只展示状态，不生成视频文件。

## 4. 演示规则

账号、模型和支付均在浏览器中模拟，不创建真实账号，也不调用视频平台、模型或支付服务。输入真实链接不会解析真实内容。

- 浏览器只保存演示邮箱、会员标记和当日额度，不保存密码
- 可输入虚构邮箱和至少 6 位的虚构密码，也可使用演示账号
- 原型中的无限总结与模拟付款仅用于展示，实际应用采用 8～50 字符密码和明确每日额度
- 需要真实下载、AI、历史或付款时，使用实际应用的启动入口

## 5. 文件与布局

四个 HTML 均包含页面结构、样式、脚本和图片，修改时直接编辑对应文件。演示页面与正式 Vue 应用分别维护，避免把模拟逻辑带入实际业务。

| 文件 | 作用 |
|------|------|
| index.html | 首页与功能入口 |
| workbench.html | 视频和四个 AI 视图 |
| comparison.html | 同尺寸布局对比 |
| gallery.html | 内嵌截图和状态预览 |

页面采用蓝白配色和圆角卡片，内容区最大 1760px，正文 16px。1100px 及以下工作台改为单栏，640px 及以下视频卡纵向展示、四个标签分两行，工具栏允许换行。
