# SaveAny 高保真交互原型

这套原型按照已确认的方案 B 制作，并在你选定的 A 舒展版基础上，更新为 2026-11-01 确认的放大适配版。包含首页、视频工作台、四个 AI 视图，以及账号、额度与模拟会员流程。每个 HTML 已合并页面结构、CSS、JavaScript、Logo 与所需图片，无需安装前端依赖。

四个可交付文件分别是 `index.html`（首页）、`workbench.html`（交互工作台）、`comparison.html`（放大前后对比）、`gallery.html`（截图预览）。每个文件都能独立打开；如需页面之间跳转，把这些 HTML 放在同一个目录即可。

## 打开预览

最简单的方式是直接双击 `index.html`。如果希望使用和本次浏览器验收相同的方式，在项目根目录执行下面的命令，再打开浏览器地址。

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory prototypes
```

- 首页：http://127.0.0.1:4173/index.html
- 视频工作台：http://127.0.0.1:4173/workbench.html
- 截图预览：http://127.0.0.1:4173/gallery.html
- UI 放大前后对比：http://127.0.0.1:4173/comparison.html

本次已启动该预览服务。以后如果地址无法打开，重新运行上面的命令即可；停止服务按 Ctrl+C。浏览器对直接打开文件的剪贴板与本地存储支持可能有所不同，遇到限制时可使用 HTTP 预览。

## 照着体验完整流程

先用示例视频走一遍成功流程，再用“演示场景”检查异常。无需真实账号、API Key 或银行卡。

| 步骤 | 你要做什么 | 应该看到什么 |
| --- | --- | --- |
| 1 | 首页点击“B 站学习教程”，再点“解析视频” | 工作台展示加载骨架屏，然后出现视频信息与画质选择 |
| 2 | 点击“登录并生成总结”，选择“使用演示账号进入” | 自动整理摘要，完成后今日额度减少一次 |
| 3 | 选择 720p 并点击“下载视频” | 显示准备、进度和完成反馈；明确标注未下载真实视频 |
| 4 | 切换“字幕文本”，展开全部，分别导出 SRT/VTT/TXT | 字幕列表展开，浏览器下载对应格式的实际示例文件 |
| 5 | 切换“思维导图” | 可折叠节点、拖动、缩放、按钮平移、适应画布与全屏 |
| 6 | 导出 SVG 和 PNG | 下载矢量图，以及 4480 × 3760 的高清 PNG |
| 7 | 切换“AI 问答”，选择推荐问题并追问 | 预设回答逐步显示，对话保留；输入不匹配时会说明演示范围 |
| 8 | 打开“演示场景”，选择“今日 AI 额度用尽”并应用 | 提示明天恢复、升级 VIP 或重置演示额度 |
| 9 | 点击升级 VIP，选择支付结果并模拟开通 | 分别可体验失败重试、取消、成功；成功后总结不限次数 |
| 10 | 在“演示场景”切换无字幕或各种失败 | 显示对应空状态或重试入口；无字幕和 AI 失败仍能下载 |
| 11 | 在顶部更换 YouTube 链接，或退出账号 | 新视频清除旧内容；退出后显示登录引导 |

账号注册与登录都是本地演示。可以输入虚构邮箱与至少 6 位的虚构密码，也可以一键使用演示账号；密码不会保存。免费额度按邮箱与本机日期计算，在当前浏览器保存。视频下载不要求登录。

## 演示边界

原型的目标是验证信息架构、视觉与操作体验。视频信息、摘要、字幕和问答是内容一致的示例数据，没有调用真实视频解析、模型或支付服务；输入真实链接也不会解析其真实内容。B 站示例的标题、作者、播放数均为场景数据。YouTube 短片示例的分析文本也经过演示改编。

字幕与导图导出会生成真实本地文件。视频下载仅演示操作状态，不会生成伪装成视频的文件。VIP 标记只影响本地原型，不会产生真实交易。
