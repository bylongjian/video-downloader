## 检查中修正的问题

检查发现页头原先受外层容器限制，滚动时不能吸顶，已将吸顶定位移到外层并重新验证。手机导图工具栏调整为两行等宽按钮，避免按钮拥挤。最终弹窗截图关闭入场动画，并先关闭浮动提示，展示稳定状态。

## 验收脚本

脚本通过浏览器中的按钮、输入与键盘验证流程，不直接调用应用内部方法来替代用户操作。脚本中的页面读取仅用于断言布局、状态和全屏结果。

- `qa/core-flow.js`：成功主流程、字幕/导图导出、问答。
- `qa/states-and-membership.js`：异常恢复、额度、会员、账号切换。
- `qa/mobile-and-layout.js`：响应式、手机导航、弹窗、导图操作、减少动态效果。
- `qa/final-visual-pass.js`：吸顶、移动端导图、弹窗稳定状态、A 版默认样式回归。

上述流程运行均未捕获到页面 JavaScript 异常。截图对比页曾因未配置 favicon 出现一次 404，已添加本地 Logo 图标；这不影响交互。最终仍需用户在自己常用的浏览器与真实手机上体验手感，本次没有声称测试 Safari、Firefox 或真实移动设备。

## 单文件合并回归

后续按用户要求，将四个页面分别合并为自包含 HTML。CSS、JavaScript、Logo 和截图均已内嵌；页面之间仍使用同目录的 HTML 链接。原始模板和打包脚本已在最终清理时删除，后续直接维护这四个 HTML。

`qa/standalone-smoke.js` 在阻断所有非文档资源请求的条件下通过 16 项检查：样式与 Logo、首页进入工作台、登录、AI 摘要、字幕导出、导图缩放与 SVG 导出、问答、返回首页、对比与图库图片内嵌、图库放大关闭、375px 布局、脚本错误与资源请求检查。结果为零页面脚本异常、零外部 CSS/JS/图片/字体请求。另对四个 HTML 中所有内嵌脚本执行 Node 语法检查，全部通过。

## UI 放大与适配复查（2026-11-01）

用户已确认本轮 UI 调整完成；此前核心 MVP 的验收结论保持有效。测试证据仅表示本机 Edge（Chromium）下的检查，不虚报其他浏览器兼容性实测。
